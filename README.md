# Geospatial Data Analysis
This project analyzes location-based business expansion opportunities in Madurai using geographic and sales data.

## Objective
Identify high-demand areas with low coffee shop presence.

## Tools Used
- Microsoft Excel
- Google My Maps
- Microsoft Word

## Analysis Performed
- Opportunity score calculation
- Demand analysis
- Geographic visualization

## Key Findings
Areas like Mattuthavani and Bibikulam showed strong business expansion potential due to high population and fewer existing coffee shops.
